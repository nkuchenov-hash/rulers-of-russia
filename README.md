# Правители России / Rulers of Russia

Модульный исторический сайт, построенный вокруг прокручиваемой хронологии правителей России.

Главная архитектурная идея: **одна продуктовая дизайн-система + меняющееся Historical Visual State**. Исторический период способен менять визуальную материю интерфейса, но не разрушает навигацию, доступность и базовую компонентную логику.

## Сейчас заложено

- единая семантическая система дизайн-токенов;
- многослойный Historical Visual State;
- движок слияния визуальных слоёв;
- модульный контракт страницы правителя;
- реестр модулей;
- контентная схема правителя;
- динамический маршрут `/rulers/[slug]`;
- отдельные границы Timeline и Map subsystem;
- демонстрационные состояния: Екатерина II, Павел I, Александр I, 1917, Ленин, Сталин, Новое время;
- правила, что исторический слой имеет и не имеет права менять.

## Важно

Состав и внутренняя композиция модулей пока **не считаются утверждёнными**. Сначала они должны быть отдельно разобраны и согласованы.
