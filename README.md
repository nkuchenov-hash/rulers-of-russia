# Правители России

Интерактивная историческая система о правителях России.

Для AI-разработки сначала читать `AGENTS.md` (карта настоящих исходников, обязательные контрактные документы и проверки). Результат статического аудита 17.10.2026: `docs/DOCUMENTATION_PARITY_2026-10-17.md`.

## Текущий этап

Проект находится на этапе Core Design System + page architecture. Главная страница проекта — канонический интерактивный skeleton будущей страницы правителя. Это не отдельный mockup: она собрана из тех же компонентов, Historical Visual State tokens и module contracts, которые должны использоваться в реальном сайте.

### Канонические слои

- `src/components/core-system/CoreDesignSystemSkeleton.tsx` — живая структура страницы.
- `src/design-system/components/BackgroundModule.tsx` — внешний фон/ambient layer как самостоятельный Core-модуль.
- `src/modules/core/modulePassports.ts` — единый реестр внутреннего устройства модулей для Core Inspector.
- `src/historical-state/` — Historical Visual State resolver и визуальные слои эпох/периодов/правлений.
- `src/design-system/tokens/base.css` — базовые semantic tokens.
- `src/app/page.tsx` — рендерит каноническую систему напрямую.

Временные standalone HTML-preview удалены. Параллельных копий интерфейса в проекте быть не должно.

## Историческая карта: статус географической приёмки (2026-11-03)

Маршрут: [`/territory/`](https://nkuchenov-hash.github.io/rulers-of-russia/territory/).

**Карта не прошла полную независимую географическую приёмку.** Генерация History Core (13 980 из 13 980 месяцев), внутренний strict audit, успешный CI и публикация GitHub Pages подтверждают разные технические свойства, **но не** точность исторических границ.

На 2026-11-03 сохраняются следующие подтверждённые препятствия:

- Для 1520–1599 в ранее выполненной независимой проверке были зафиксированы 26 ошибок из 26 сравнений. Последующие прогоны с непригодными экспортами или несопоставленными слоями не являются успешными сравнениями и не снимают эти ошибки.
- Экспорты Runivers, включая ресурсы 5383 и 5385, содержат топологически некорректные полигоны (отверстие пересекает внешнюю границу). Такие данные отклоняются, а не исправляются догадками.
- Для 1946–1991 недоступность независимых ресурсов не позволяет считать период географически проверенным.
- Не завершены подтверждение точных исторических переходов по независимым источникам и проверка прав на использование каждого набора геометрии.

Правила приёмки: не снижать географические пороги ради прохождения проверки; не считать отсутствие сравнений успехом; не переносить геометрию внешних источников в production без подтверждённых прав; проверять глобус, плоскую карту и мобильные экраны отдельно. После исправления конкретных контуров повторять независимое сравнение и сохранять воспроизводимый отчёт.

Актуальное состояние сборки, Actions и live SHA необходимо проверять отдельно: эта секция — датированный снимок **ограничений приёмки**, а не утверждение о текущем деплое.
