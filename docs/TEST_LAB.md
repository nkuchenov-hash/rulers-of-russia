# Test Lab

`/lab/` — постоянная тестовая поверхность проекта «Правители России».

## Зачем она нужна

Test Lab показывает результат всей системы до наполнения конкретной публичной страницы:

- Core Design System;
- модульный renderer страницы правителя;
- data contracts;
- Historical Visual State;
- Media rules;
- Core Inspector;
- интерактивные настройки разрешённых параметров.

## Главное правило

Test Lab **не является отдельным preview и не содержит копии интерфейса**.

Он вызывает тот же `CoreDesignSystemSkeleton`, который используется основной страницей, и передаёт ему структурированную тестовую запись `labRulerPageData`.

Если компонент, data contract или HVS меняется, `/lab/` должен измениться автоматически, потому что отдельного второго renderer не существует.

## Канонический тестовый правитель

Для Test Lab используется Пётр I. Это постоянная содержательная fixture для проверки Hero, карты, фактов, тематических карточек, хронологии и Imperial HVS — не абстрактный «тестовый правитель».

## Данные

Тестовая запись живёт в:

`src/content/rulers/labRulerPageData.ts`

Её модель живёт в:

`src/content/rulers/pageModel.ts`

Она нужна для проверки поведения backend/data layer: enabled/disabled modules, отсутствие media asset, длинные имена, разные количества событий, фактов, thematic cards и timeline nodes.

## Inspector

В `/lab/` Inspector включён по умолчанию.

Паспорт модуля содержит интерактивное дерево «Состав блока», устроенное по принципу Layers в Figma:

- модуль;
- группы;
- вложенные модули;
- конкретные элементы.

Выбор элемента в дереве должен:

1. выбрать его паспорт;
2. подсветить реальный элемент на странице;
3. прокрутить страницу к нему;
4. показать разрешённые настройки;
5. применять допустимые визуальные настройки live к реальному renderer.

Элементы, чьи значения определяются данными или историческими источниками, не должны получать произвольные визуальные/контентные controls только ради редактирования.

## Запрет

Не создавать новые standalone HTML preview, параллельные renderer'ы или отдельные «демо-копии» страницы. Любая визуальная проверка Core должна идти через `/lab/`.
