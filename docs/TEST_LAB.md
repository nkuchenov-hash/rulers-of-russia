# Test Lab

`/lab/` — постоянная живая тестовая страница проекта «Правители России».

## Главное правило

Test Lab показывает **только результат сайта**. На `/lab/` запрещены Layers, Properties, Inspector, служебные бейджи, dev-панели и любые другие инструменты.

Он использует тот же `CoreDesignSystemSkeleton`, что и публичные страницы, и передаёт ему реальные тестовые данные Петра I. Поэтому изменение renderer, data contract, HVS или media rules должно сразу проявляться на `/lab/` без отдельной копии интерфейса.

## Канонический тестовый правитель

Для Test Lab используется Пётр I. Это только входные данные тестовой страницы. Core Design System, Inspector, module contracts и generic renderer не должны содержать Петра I или любого другого конкретного правителя.

Данные Test Lab живут в:

`src/content/rulers/peterILabRulerPageData.ts`

Модель страницы живёт в:

`src/content/rulers/pageModel.ts`

## Редактор

Инструменты вынесены в отдельный маршрут:

`/studio/`

В редакторе:

- слева — Layers всей страницы;
- по центру — тот же живой renderer;
- справа — Properties выбранного элемента.

Критическое правило: редактор не имеет права менять ширину, масштаб, spacing или композицию renderer. Панели — только editor shell вокруг/поверх той же страницы.

## Типографика

На сайте запрещён текст меньше 16 pt. Исключение возможно только после прямого продуктового решения.

## Запрет

Не создавать standalone HTML preview, параллельные renderer'ы или отдельные демо-копии страницы. `/lab/` — живая страница результата, `/studio/` — редактор того же renderer.
