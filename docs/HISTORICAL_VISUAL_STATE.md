# Historical Visual State

## Определение

Historical Visual State (HVS) — набор слоёв, которые формируют текущую визуальную атмосферу страницы в конкретной точке хронологии.

## Слои

### 1. Core
Общий современный премиальный интерфейс продукта.

### 2. Polity / cultural layer
Широкое историческое родство: Московское государство, Империя, Революция, СССР, Российская Федерация и т.п.

### 3. Period layer
Более узкая визуальная культура времени: поздний XVIII век, александровский ампир, поздняя империя, революционный 1917, раннесоветский период, сталинский период, оттепель, поздний СССР, постсоветское время и т.п.

### 4. Reign layer
Характер конкретного правления. Может быть слабым или сильным.

### 5. Rupture/context layer
Краткосрочное состояние, когда сама историческая структура требует другой композиционной энергии: революция, двоевластие, междуцарствие, временное правительство, война, конституционный кризис и т.п.

## Сила override

Каждый слой получает `intensity` от 0 до 1.

Это позволяет сделать:

- близкие правления — родственными;
- заметный переход Екатерина II → Павел I → Александр I;
- сильный разрыв Империя → 1917;
- очень сильное различие Ленин → Сталин;
- самостоятельное Новое время.

## Переходы

Переход между правителями не обязан быть переключателем. Часть токенов может плавно интерполироваться:

- фон;
- поверхность;
- border tone;
- map treatment;
- texture intensity;
- ambient light.

Другие параметры должны переключаться дискретно после порога:

- display font family;
- layout accent mode;
- image framing mode.

## Никакой исторической карикатуры

Красный цвет не равен СССР. Золото не равно Империи. Пергамент не равен древности.

Состояние строится из композиции, типографики, материалов, изображения, ритма и motion вместе.
