# Timeline / Chronology Subsystem

Timeline — глобальный навигационный позвоночник сайта.

Он знает:

- текущую историческую позицию;
- соседних правителей/режимы;
- переходы и перекрытия;
- периоды без единственного правителя;
- ruptures: 1917, междуцарствия, временные правительства и другие нестабильные состояния.

## Важное следствие

Хронология не должна предполагать, что в любой момент существует ровно один линейный объект `ruler`.

Модель должна поддерживать:

- competing authorities;
- provisional governments;
- regencies;
- interregnum;
- collective leadership;
- overlapping claims.
