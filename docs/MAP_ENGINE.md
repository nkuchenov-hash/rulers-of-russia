# Map Subsystem

Карта — отдельный движок, а не декоративная картинка внутри одного модуля.

## Задачи

- границы государства по датам;
- изменения территории;
- города и столицы;
- походы и военные кампании;
- дипломатические изменения;
- точки событий;
- сравнение начала и конца правления.

## Контракт

Страница передаёт карте `mapStateId`, временную позицию и overlays. Historical Visual State задаёт художественный treatment через токены. Геометрия и исторические данные от оформления не зависят.
